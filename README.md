# TaskFlow

A modular productivity dashboard built with Vanilla JavaScript.

## Features

- **Task CRUD**: Create, read, update, and delete tasks easily.
- **Search**: Quickly find tasks by title.
- **Filtering**: Filter tasks by category, priority, or status.
- **Sorting**: Organize tasks by newest, oldest, due date, priority, or alphabetically.
- **Priority Management**: Assign and track task priorities (Low, Medium, High).
- **Categories**: Group tasks into Work, Personal, Study, or Other.
- **LocalStorage Persistence**: Seamlessly save your tasks and preferences locally in the browser.
- **Dark/Light Mode**: Toggle between themes for comfortable viewing.
- **Dashboard Statistics**: Get quick insights on total, pending, completed, and overdue tasks.
- **API Integration**: Fetches a daily motivational quote to keep you inspired.
- **Keyboard Shortcuts**: Work faster with global shortcuts (e.g., `N` for new task, `/` for search, `Esc` to close modals).

## Architecture

The application is structured using robust software design patterns to ensure maintainability and separation of concerns:
- **MVC (Model-View-Controller)**
- **Observer / Pub-Sub**
- **Factory Pattern**

## Tech Stack

- **HTML**
- **CSS** (Tailwind CSS for utility-first styling)
- **JavaScript ES6+**

TaskFlow serves as a practical implementation of various core and advanced JavaScript concepts:

- **DOM Manipulation**

- **ES Modules**
